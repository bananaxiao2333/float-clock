FloatClock - a borderless, transparent, always-on-top T+/- countdown overlay
============================================================================

Everything in this folder came out of the same release archive, so whichever
platform you are on, the first thing to do is unpack the .zip. Do not run the
executable straight out of the archive viewer.


WHAT YOU SHOULD SEE
-------------------

    T-02:29:00            main title: time left until the offset moment
      T-00:29:00          subtitle: time elapsed since the target time
    20:29:00 | +02:00:00  third line: target time and offset

There are two moments:

    T   the target time you configure            (the subtitle counts from it)
    M   T + the offset                           (the main title counts to it)

Both flip from T- to T+ on their own once they are in the past, and both fire
system notifications on the way in.


RUNNING IT
----------

macOS     Double-click FloatClock.app.
          The first launch of an unsigned app is blocked by Gatekeeper:
          right-click the app, choose Open, and confirm once. Or clear the
          quarantine flag from a terminal:

              xattr -dr com.apple.quarantine FloatClock.app

          Unpack the zip with Finder. It keeps the executable bit; a bare
          binary downloaded from a browser does not, and Finder then hands it
          to TextEdit instead of running it.

Windows   Double-click float-clock.exe.
          SmartScreen may warn about an unknown publisher: More info -> Run
          anyway.

Linux     chmod +x float-clock
          ./float-clock
          Unpack with `unzip` (or your file manager), which restores the
          executable bit.


WHERE THE CONFIG FILE IS
------------------------

On the very first run FloatClock writes a config file and opens its settings
window. The config file lives here:

    macOS     ~/Library/Application Support/FloatClock/config.toml
    Windows   %APPDATA%\FloatClock\config.toml
    Linux     ~/.config/float-clock/config.toml   (or $XDG_CONFIG_HOME)

You can always ask:

    float-clock --config-path

Precedence, highest first:

    1.  --config <path>
    2.  $FLOAT_CLOCK_CONFIG
    3.  ./config.toml in the current directory
    4.  the per-user location listed above

Save the file and the running overlay picks the change up within about a
second. There is no need to restart it.

config.example.toml next to this file documents every single setting. Copy
whichever parts you want into your config.toml.


THE PARTS YOU WILL ACTUALLY WANT TO CHANGE
------------------------------------------

[time] target
    When the countdown points at. Accepts:

        2026-09-19T20:29:00                   an exact date and time
        2026-09-19 20:29                      same thing, space separated
        2026-09-19                            midnight that day
        20:29                                 today at 20:29, rolling over to
                                              tomorrow once it has passed -
                                              use this for a daily schedule
        +1h30m                                relative to right now

[time] offset
    How far the main title's moment M sits from the target T. Negative values
    count down to a moment *before* the target, which is what you want for a
    reminder:

        -00:05:00    five minutes before the target
        0            M and T are the same moment
        +2h          two hours after the target

[display] color / main_size / sub_size
    Green, bold, monospace is the default look: #00FF66 at 46pt, with an 18pt
    subtitle.

[notify] before / after
    Lists of seconds relative to each moment. The defaults are
    [3600, 1800, 900, 600, 300, 180, 120, 60, 30, 10, 5, 3, 2, 1] before and
    [1, 5, 30, 60, 300] after.


CONTROLS
--------

    drag with the left mouse button      move the overlay
    right-click                          lock / unlock (solid = locked)
    double-click                         settings window
    Cmd/Ctrl + L                         lock / unlock
    Cmd/Ctrl + ,                         settings window
    Cmd/Ctrl + R                         reload the config from disk
    Cmd/Ctrl + H                         hide / show the overlay
    Cmd/Ctrl + Q                         quit

On macOS and Windows there is also a tray icon - in the menu bar and in the
notification area respectively. It has show/hide, lock, settings, open config
file, show config in folder, reload and quit.

Linux has no tray icon in this build: the only options there are XEmbed
(X11 only, dead on Wayland) or a D-Bus StatusNotifierItem, and both would drag
a GTK3 or D-Bus runtime into a binary that currently links nothing but libc.
Right-click, the keyboard shortcuts and the config file cover the same ground.


USEFUL COMMAND LINE FLAGS
-------------------------

    float-clock --init-config           write a fresh default config
    float-clock --config-path           print which config file would be used
    float-clock --print                 print the state and the next reminders
    float-clock --test-notify           check that notifications work
    float-clock --diagnose              print environment diagnostics
    float-clock --render-png out.png    render the overlay to a PNG
    float-clock --help                  everything else
